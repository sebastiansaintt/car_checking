# Layout Principles

This project follows editorial software principles.

Not landing pages.

Not marketing websites.

Not generic dashboards.

Just Elegant Software - Minimalism Computing

---

# Reading Order

Every page must answer:

Where am I?

↓

What is this?

↓

What can I do?

↓

What should I read first?

↓

What should I do next?

---

# Mandatory Structure

Breadcrumb

↓

Title

↓

Description

↓

Primary Actions

↓

Filters

↓

Main Content

↓

Secondary Information

---

# Composition

Always prioritize vertical reading.

Information flows from top to bottom.

Never require users to decide whether to read left or right first.

---

Avoid:

Large two-column layouts.

Card grids.

Masonry layouts.

Floating widgets.

---

Use two columns only when:

- secondary information supports the main content

Never split the primary workflow.

---

# Containers

Content naturally occupies the viewport.

Avoid narrow centered layouts.

Avoid oversized whitespace.

---

# Main Workflow

Primary tasks always occupy the full width.

Secondary panels belong below the workflow.

The interface should feel like reading a document.

---

# Density

Scrolling should reveal new information.

Not empty space.

---

# Alignment

Everything aligns to a grid.

Nothing floats.

Nothing feels arbitrary.

---

# Editorial Principles

Typography creates rhythm.

Spacing separates.

Alignment structures.

Motion communicates.

Cards never create hierarchy.
