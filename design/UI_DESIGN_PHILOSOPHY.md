# Philosophy

The interface should feel like professional industrial software.

Never like a marketing website.

Never like a generic AI dashboard.

The content is always more important than the interface.

Every pixel must have a purpose.

Prefer removing over adding.

Prefer structure over decoration.

Prefer typography and icons over color.

Prefer alignment over visual effects.

Prefer workflows over dashboards.

Prefer clarity over visual impact.

Prefer editing over presenting.

---

The interface should communicate:

- Confidence
- Clarity
- Efficiency
- Calmness

---

The interface should feel:

- Human Interface Guideline Apple
- Minimalist
- Simplist
- Elegant
- Smooth
- Fluent

---

The user should immediately understand:

- Where they are.
- What they are looking at.
- What they should do next.
- What action is expected.

---

The interface should naturally guide users through a workflow.

Not through widgets.

Dashboards summarize.

Workflows accomplish tasks.

Always prioritize the workflow.

---

Avoid:

- Generic SaaS dashboards
- Marketing layouts
- Decorative UI
- Floating cards
- Giant spacing
- AI-looking interfaces
- Decorative illustrations
- AI Design UI
- Colorful
