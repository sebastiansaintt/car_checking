# Theme

Default theme: Light.

Design for clarity first.

The interface should feel calm, precise and unobtrusive.

Content should always receive more visual emphasis than the UI.

---

# Colors

Use a restrained monochrome palette.

## Background

#FFFFFF

## Secondary Background

#FAFAFA

## Surface

#FFFFFF

## Border

#E5E7EB

## Primary Text

#111827

## Secondary Text

#6B7280

## Tertiary Text

#9CA3AF

Reserve accent colors exclusively for semantic meaning:

- Success
- Warning
- Error
- Information

A single brand accent color may be used for:

- Primary actions
- Active navigation
- Focus states
- Selected items

Never use color to create hierarchy.

Never use color as decoration.

Never use gradients.

Never use neon.

---

# Radius

Radius should be subtle and consistent.

Containers

8px

Cards

12px

Inputs

8px

Buttons

8px

Tables

8px

Dropdowns

10px

Dialogs

12px

Avoid excessive rounding.

Avoid bubble interfaces.

---

# Borders

Borders define structure.

Use:

- 1px borders
- Neutral colors
- Low contrast

Prefer borders over shadows.

---

# Shadows

Shadows should be almost invisible.

Use only to reinforce depth.

Prefer:

- Soft shadows
- Low opacity
- Small blur radius

Blur and transparency are preferred over heavy elevation.

---

# Typography

Typography creates hierarchy together with spacing.

Use Inter.

Hierarchy should come from:

- Size
- Weight
- Spacing
- Alignment

Never rely on color alone.

Typography scale:

- Display
- Heading XL
- Heading L
- Heading M
- Heading S
- Body
- Caption
- Metadata

Keep line lengths comfortable.

Maintain generous line height.

---

# Spacing

Use a consistent 4pt grid.

Spacing scale:

4

8

12

16

20

24

32

40

48

Whitespace should improve comprehension.

Never add empty space for decoration.

Use spacing before introducing borders.

---

# Layout

Use the available viewport efficiently.

Design responsive layouts.

Maintain consistent alignment.

Prefer structured grids.

Reading interfaces may use narrower content widths.

Application interfaces should maximize usable workspace without feeling crowded.

---

# Density

Optimize for clarity.

Prefer medium density.

Increase density only when it improves productivity.

Reduce visual noise before reducing spacing.

Information should remain scannable.

---

# Surfaces

Minimize visual layers.

Prefer flat surfaces.

Use subtle blur and transparency only when they improve hierarchy.

Avoid stacked cards.

Avoid unnecessary containers.

---

# Components

Components should be quiet and systematic.

Prefer:

- Buttons
- Inputs
- Selects
- Tables
- Popovers
- Sheets
- Dialogs
- Tooltips

Keep variants minimal and predictable.

Every component should behave consistently.

---

# States

State should be immediately recognizable.

Support:

- Default
- Hover
- Active
- Focus
- Disabled
- Loading
- Success
- Error

Focus indicators must always remain visible.

Never hide state changes.

---

# Design Principles

Reduce before adding.

Prefer clarity over personality.

Prefer consistency over originality.

Prefer function over decoration.

Every visual decision should help users understand, navigate or complete a task.

The interface should feel invisible.
