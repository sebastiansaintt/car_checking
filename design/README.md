# Design System

These files define the design language of the project.

Read them in this order:

1. UI_DESIGN_PHILOSOPHY.md
2. DESIGN_TOKENS.md
3. LAYOUT_GUIDE.md
4. COMPONENT_RULES.md
5. MOTION_GUIDE.md
6. DESIGN_REVIEW_CHECKLIST.md

These documents override default UI conventions.

When multiple implementations are possible:

Choose the simplest.

Choose the quietest.

Choose the most compact.

Choose the most readable.

Choose the one that prioritizes workflow over aesthetics.

Never generate generic AI interfaces.

Never generate marketing-style dashboards.

Always think like enterprise software.
