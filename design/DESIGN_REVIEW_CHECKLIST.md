# Clarity

- Is the purpose of this page immediately obvious?
- Can users identify where they are within seconds?
- Is the primary task immediately clear?
- Does every visible element have a purpose?
- Can anything be removed?

---

# Information Hierarchy

- Is there a single dominant heading?
- Does typography create the visual hierarchy?
- Is spacing reinforcing the hierarchy?
- Is the primary action immediately identifiable?
- Are secondary actions visually subordinate?

---

# Navigation

- Is the current location obvious?
- Is navigation predictable?
- Is the active section clearly indicated?
- Are breadcrumbs only shown when they add value?
- Can users move between related areas effortlessly?

---

# Layout

- Does the layout follow a natural reading flow?
- Is there one clear primary workflow?
- Is related information grouped together?
- Is the available viewport used efficiently?
- Does the layout remain balanced at different screen sizes?

---

# Content

- Is the most important information visible first?
- Can users scan the page quickly?
- Is unnecessary information hidden until needed?
- Is progressive disclosure applied appropriately?
- Does every piece of content support the current task?

---

# Components

- Are components consistent across the interface?
- Can multiple components be simplified into one?
- Is a simpler component sufficient?
- Are visual containers used only when necessary?
- Do components communicate state clearly?

---

# Density

- Is enough information visible without scrolling?
- Is whitespace improving comprehension?
- Is information dense without feeling crowded?
- Can more value fit without increasing cognitive load?

---

# Visual Design

- Does the interface feel calm?
- Is the palette predominantly monochromatic?
- Are accent colors reserved for meaning?
- Are borders preferred over shadows?
- Are shadows subtle?
- Is depth created with restraint?
- Is the interface free from visual noise?

---

# Motion

- Does motion preserve continuity?
- Does every animation communicate state?
- Are transitions subtle and fast?
- Does motion avoid unnecessary attention?
- Would the interface still work without animation?

---

# Workflow

- Does the interface guide users toward completion?
- Is the next step always obvious?
- Are secondary actions available without competing with the primary flow?
- Are errors easy to recover from?
- Does every interaction reduce friction?

---

# Consistency

- Are spacing values consistent?
- Are typography styles reused?
- Are component variants predictable?
- Are interaction patterns consistent across screens?
- Does every page feel like part of the same system?

---

# Final Evaluation

Ask yourself:

- Does the interface feel quieter than it is impressive?
- Is the content more prominent than the UI?
- Does every visual decision improve usability?
- Would removing an element make the experience worse?

If the answer is **no**, remove it.

# Reference Quality

The interface should feel closer to:

- Apple
- Linear
- Figma
- Notion
- Vercel
- GitHub
- Stripe Dashboard
- Arc

Not:

- Dribbble concepts
- Marketing landing pages
- Trend-driven UI
- Glassmorphism showcases
- Generic AI dashboards
- Decorative interfaces
